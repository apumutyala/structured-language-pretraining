# Prior work informing this experiment

The directly relevant predecessor is [Certified semantic memory research](https://github.com/apumutyala/certified-semantic-memory-research).
It is a separate, narrowly scoped workflow experiment, not another active
language-model campaign or evidence that alignment has been solved.

## What carries forward

The predecessor represents all modeled worlds consistent with retained
evidence. A learned component proposes a memory update, while an exact kernel
checks whether the update preserves the declared contract. The host retains
authority over permissions and the attempt budget. A persistent backend runs
the concrete Lean transition whose conditional properties were proved.

This repository already includes the reusable memory kernel, Lean sources and
selected verification tools. The predecessor release adds the procedural
workflow generator, learned proposal models, exact and fallback controls,
precision experiments and the learned-to-Lean replay tools. It is useful for
reproducing the earlier experiment and understanding its limits.

## The result that shaped the current comparison

In the recorded development replay, the learned typed proposer completed
12 of 20 workflows. An empty proposal that invoked the exact fallback completed
20 of 20; retaining the full superset completed none. The combined replay
matched 367 state updates and 1,468 assertion queries, with no recorded-world
omissions or false approved assertions on those traces.

These are historical, scoped results. They establish neither a learned
efficiency advantage nor general truthfulness. Reproducing the exact learned
numbers requires the specified training lineage, artifacts and runtime. The
public predecessor explains those requirements and offers a checkpoint-free
symbolic control demonstration.

The useful lesson is that preserving a safety contract can coexist with poor
task performance. The current study therefore asks whether initial language
learning gains useful generalization or cost efficiency over an equally
informed external workspace. It measures support, intended-answer correctness,
coverage, fallback reliance and total cost separately. The exact baseline must
remain competitive and visible.

## Boundaries

The predecessor's three-bit workflow theorem covers its declared model and
assumptions. It does not certify the new supported-record implementation,
the neural model, evidence authenticity or external-world truth. False but
consistent observations remain outside its containment guarantee. The current
program needs its own proof-to-execution connection and learned comparison.

This release is presented as prior implementation and negative evidence. It
does not enlarge the current experiment into several separate research tracks.
